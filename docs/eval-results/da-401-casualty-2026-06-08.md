score is left unscored and is re-runnable via `--resume`.

### Step 3 — Inspect the executed package for guard catches (if it survived)

```bash

PKG=$(grep -E 'da-401' "$RUN/journal.jsonl" | python -c "import sys,json; \
  [print(json.loads(l).get('package_dir') or '') for l in sys.stdin]" | grep . | head -1)
echo "package_dir=$PKG"
[ -n "$PKG" ] && [ -d "$PKG" ] && {
  python -m json.tool "$PKG/WORKFLOW.json" \
    | grep -nE '"state"|blocked|missing_artifact|validation_failed|sentinel' | head;
  ls -la "$PKG/runtime/outputs"/*/ 2>/dev/null | head;
  cat "$PKG/runtime/validation-reports.jsonl" 2>/dev/null | tail;

```

By default the per-run package tree is cleaned at run end; only
`ECAA_EVAL_KEEP_SCRATCH=1` retains it. If the package was cleaned the diagnosis is
journal-only.
