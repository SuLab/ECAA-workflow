## Added

### Claim-verification: fabrication detection (VF series) + ground-truth corpus
- **Soft `Suspicious` status** added alongside Verified / Mismatch / Unverifiable, with a corpus-oracle schema (`94e14c1`). `Suspicious` catches quantitative claims about an entity absent from the cited table (VF-0, `a54aa68`).
- **New verifier checks** for narrative-vs-table fabrication classes: p-value laundering — a raw p quoted under an adjusted label (VF-8, `8d44f79`); linear-fold magnitude overclaims (VF-4, `b5784fc`); aggregate count claims such as "2209 genes upregulated at FDR<0.05" (VF-16, `e93405c`); wrong symbol↔Ensembl pairings (VF-13, inert-by-default in core, `4739911`); fabricated literature concordance as a Mismatch (VF-15a, `777abe0`); a structured claim citing a phantom evidence file as a Mismatch (VF-1, `322fbd8`); ratio-family effect columns pivoting at 1.0 rather than 0 (VF-19, `50952ea`).
- **Extractor improvements**: prose-format log2 magnitudes ("log2FC of 3.5", VF-3, `e394ef1`); pair-or-demote ambiguous trailing value lists (VF-12, `3fc784b`); recover phantom/ambiguous table citations via sibling discovery (VF-11, `522bc02`).
- **Planted-fabrication ground truth** with anti-regression guards and precision/recall metrics (`66208ab`); corpus grown to ~85 scenarios across literature, structured, proteomics, multi-table, variant/GWAS, scRNA, microbiome, methylation, RankTopN, GSEA, and time-series-forecast modalities (`58c1d41`, `da19e36`, `d536efb`, `f46890c`).

### Self-finalize harness + automatic repair
- **End-of-run package finalize**, standalone and session-free: the harness now finalizes a completed package (claim verification, audit-proof, RO-Crate PROV) without a live session (`5e959c3`, `37f9bb8` lifted orchestration into `ecaa_workflow_core::finalize`, `e4c4ab6` self-contained policy resolution, `6280153` refreshes plaintext claim-verification post-execution).
- **Automatic end-of-run repair loop** gated by `ECAA_AUTO_REPAIR` (`997e06f`).
- **Closed-loop repair orchestrator** for executed packages and a **type-aware claim-repair plan** that prefers corrections (narrative / citation / evidence-completion / review) over task re-runs (`d24bcca`, `ec20e12`).
- **Discovery decisions** promoted into `decisions.jsonl` (Decision subgraph) so auto-advanced method choices are on record; confirmatory tasks re-blocked when a Required claim-coverage gap exists (`0574366`, `16656b0`, `2faa34f`).
- **RO-Crate PROV** per-output `wasGeneratedBy`/`CreateAction` emitted at finalize (`78521f3`).

### Re-execution equivalence
- **Functional comparator** (`classify_reexecution`) plus a standalone **`reexec` CLI** that classifies a replay package against its parent (byte-identical / semantic-equivalent / acknowledged-non-determinism / unavailable / failed) and writes `runtime/reexecution.json` (`ff02fb8`).

### Depositable package export
- **`export` CLI + web-UI download** producing a clean A+B-tiered `.zip`: copies the audit/review/deposit + re-execution surface into a scratch tree, re-seals the BagIt manifest + RO-Crate, strips `.git`, and drops caches, R libraries, logs, and heartbeats (`673a614`).

### Render-as-contract (figures)
- **Package-portable render CLI** entrypoint and a **fixed post-compute figure render step**, with agent-facing figure steers rewritten to the data-table contract so figures are compute-language-independent (`9330142`, `26c1c86`, `3671684`, `b6b106d`, `2622a74`, `15084f9`).

### Eval harness
- **BiomniBench** score reported with and without a source-reliability penalty; judge rationale + per-criterion levels persisted into scorecard rows (`bc30d72`, `c192c43`).
- **Nekrutenko** per-sample macro M3 reported as the headline metric; per-row ECAA `relaunch_count`/`resolved_blocks` threaded onto the score (`89ebc5d`, `73e7868`).
- **Robustness against contract evasion** hardened across the variant + association contracts; error-matrix cells never silently dropped (any failure recorded as inconclusive-with-reason) (`8f28735`, `f195c05`, `ec1e5c5`).

## Changed

## Fixed
- **Claim-verification integrity remediation** (the keystone workstream): entity-column coverage so `gene_id`/`ensembl_id` tables load instead of being silently dropped; verifier warns rather than drops on a table-load failure; first-column entity fallback; dispatch + hardening of the `gene_symbol_ensembl_consistent` validator (`5cba103`, `598d53c`, `ed58f38`, `0d1fa30`).
- **Verifier precision**: eliminated narrative-vs-table false-positive classes — non-result tables loaded via first-column fallback, singular `prior_pmid` columns, NA-`padj` fall-through to raw p-value, and `NES`/`FWER` enrichment-score acronyms colliding with gene symbols (`99c6b6b`, `93a711c`, `8f0e3a0`, `4bb261b`); reverted a result-table claim-mining path that exploded `n_checked` (`b75ab7d`).
- **Idempotent re-finalize**: the signed verdict sink, decision sidecar, and validation-report sidecar are now replace-per-task rather than append-only, so re-finalizing a package no longer inflates counts or surfaces phantom violations (`f2b0e26`, `8d0d658`, `e48c7a5`).
- **Claim-completeness recall-floor gaps** closed, with prose-acronym and accession/sample-id deny-list patterns to suppress spurious candidate claims (`b961c1e`, `82a83af`).
- **Harness crash on finalize** from non-total float ordering fixed (`total_cmp` for float sorts) (`f372acd`); 429 / session-limit classified as transient with fail-fast group teardown (`14857cb`).
- **UI**: corrected a stale `InputsTab` comment that described chunked upload as a 501 stub when it is implemented (`41a6758`).

## Notes / known gaps (surfaced during the case-study validation)
- The **gene-symbol↔Ensembl** consistency check still errors when no output table pairs symbols with Ensembl ids in a form it recognizes, so a narrative symbol-label mistake (e.g. a top gene mislabeled) is not auto-caught against the structured table; the cross-check of report-prose `SYMBOL (ENSG…)` pairs against the in-package matrix remains an open verifier enhancement.
- The **BagIt payload manifest is intentionally partial on live emit** (post-manifest-mutated sidecars are excluded to avoid stale checksums). A frozen depositable export can safely seal the full payload; completing the manifest in the `export` path (rather than post-hoc) is a candidate enhancement.
- **Re-execution equivalence** treats `unavailable` as non-divergent: re-running only the deterministic compute stages (network-free) yields a clean pass while literature/validation outputs are recorded as unavailable.
